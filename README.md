# Share2Gemni-Extensions 🧩

Official extension repository and marketplace feed for the [Share2Gemini](https://github.com/Priydarshansingh/Share2Gemni) Android application.

## 📦 Available Extensions

| Extension | Platform | Description | Status |
| :--- | :--- | :--- | :--- |
| **Instagram Downloader** | Instagram | Download Reels, Video Posts, and Stories directly into Gemini analysis | `v1.0.0` Stable |
| **YouTube & Shorts Downloader** | YouTube | Extract YouTube videos and Shorts for Gemini AI summarization | `v1.0.0` Stable |
| **Twitter / X Media Downloader** | Twitter / X | Download videos, GIFs, and media attachments from tweets | `v1.0.0` Stable |
| **Reddit Video & Media Downloader** | Reddit | Extract videos (`v.redd.it`) and high-res images from Reddit posts | `v1.0.0` Stable |
| **Pinterest Pin Media Downloader** | Pinterest | Download Pinterest pins, idea pins, video pins, and image posts | `v1.0.0` Stable |

## 🚀 How It Works
The Share2Gemini Android app connects directly to this repository to dynamically fetch and update media extractors without requiring app updates.
